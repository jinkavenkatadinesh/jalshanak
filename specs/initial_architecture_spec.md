# Spec: JalRakshak Core Smart Water Leak Platform

## Goal
Establish a smart water leak reporting portal where citizens can submit reports with GPS coordinates and photo evidence, and water board authorities can inspect and update reports in real-time.

## Technical Details
- **Backend API**: FastAPI with Sqlite database.
- **Frontend App**: React Vite with custom Glassmorphism designs.
- **Map integration**: Leaflet Maps API.
- **Deployment**: Docker containerization.
